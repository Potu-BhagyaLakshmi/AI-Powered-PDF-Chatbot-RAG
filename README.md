# 🤖 AI-Powered PDF Chatbot using Retrieval-Augmented Generation (RAG)

### Intelligent Document Question Answering System

## 📌 Overview

The **AI-Powered PDF Chatbot** is an intelligent document-based question-answering system that enables users to interact with PDF documents using natural language.

The project leverages **Retrieval-Augmented Generation (RAG)** to retrieve relevant information from uploaded documents and generate context-aware responses using Large Language Models (LLMs).

## ✨ Key Features

- PDF document processing and text extraction
- Intelligent text chunking
- Semantic embedding generation
- Context-based information retrieval
- AI-powered question answering
- Natural language interaction with documents

## 🛠️ Tech Stack

- **Programming Language:** Python
- **AI Architecture:** Retrieval-Augmented Generation (RAG)
- **Language Models:** LLM
- **Embeddings:** Semantic Vector Embeddings
- **AI Integration:** OpenRouter API

## ⚙️ How It Works

1. Upload a PDF document.
2. Extract text from the document.
3. Split the extracted text into smaller chunks.
4. Generate embeddings for the text chunks.
5. Retrieve relevant information based on the user's query.
6. Generate an AI-powered response using the retrieved context.

## 🎯 Project Objective

The objective is to demonstrate the practical implementation of RAG technology for document understanding and intelligent information retrieval.
